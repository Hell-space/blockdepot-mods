安装指南

选择匹配的文件

在启动器中查看实例的 Minecraft Java 版版本和加载器，然后在资源目录选择同样的游戏版本与 Forge 或 NeoForge。打开模组详情可以查看每个发布包的前置依赖、适用端和注意事项。

安装单个模组

退出游戏，在启动器中打开目标实例的游戏目录，将下载的 .jar 原样放入 mods 文件夹。更新时先移出同一 Mod ID 的旧 JAR，再启动这个实例。需要前置模组的文件，请一并安装详情中注明的对应版本。

使用完整套装

将下载的 ZIP 解压到单独的文件夹，阅读其中的 README.md。套装按当次发布的版本配套，手动安装时将套装内 mods 目录里的 JAR 放入目标实例，并先移出同名模组的其他版本。

核对下载文件

在文件所在目录打开 PowerShell，将下方的文件名替换为实际名称。把输出的 SHA-256 与模组详情里的完整校验值对照，两者应一致。

Get-FileHash -Algorithm SHA256 -LiteralPath '.\文件名.jar'

使用测试工具

「测试工具」收录用于对照测试的模组，请放在单独的测试实例中。标有「待实机复测」的游玩版本可在对应文件的说明中查看状态。
